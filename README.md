# 🚢 ARN Ship Payroll System
### نظام إدارة رواتب أسطول السفن وصندوق القبطان

تطبيق مكتبي متكامل لإدارة مرتبات أطقم السفن البحرية وحسابات صندوق القبطان النقدية وفق المعايير البحرية الدولية، مطور بواسطة **عبده رجب نصار** لشركة **ARN Technology**.

## ⚡ التشغيل السريع

```powershell
# 1. تثبيت الحزم المطلوبة
pip install PyQt6 pytest

# 2. تشغيل البرنامج
python main.py

# 3. تشغيل الاختبارات الآلية
python -m pytest
```
